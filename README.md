### Featured Projects

**PulseMonitor — API Telemetry Platform**
A full-stack telemetry platform: a TypeScript Express SDK buffers up to 500 events and sends batches of 20 with up to 3 delivery attempts (never capturing request bodies, auth headers, or query strings). Events flow through project-authenticated ingestion (revocable SHA-256-hashed API keys, 50-event batch limit, 60 attempts/project/minute) into a **BullMQ** worker with PostgreSQL duplicate protection and graceful shutdown. A React + TypeScript dashboard shows request count, RPS, 5xx rate, and latency with Recharts, plus **Socket.IO** live updates and REST recovery after reconnects. Secured sessions use hashed 32-byte tokens with 8-hour expiry and login rate limits. Packaged as **5 Docker Compose services**, verified with **65 backend tests**, UI tests, and a Playwright browser workflow.
`Tech Stack: React, TypeScript, Express, PostgreSQL, Redis, BullMQ, Socket.IO, Docker`

**Folio — AI Conversation Workspace**
A full-stack AI chat app integrating the **OpenAI Responses API**. The Express + Prisma + PostgreSQL backend exposes 6 REST endpoints with UUIDs, indexed message history, cascade deletion, and migrations. Duplicate and concurrent requests are prevented with transactional processing using **PostgreSQL advisory locks**, and the API is protected with **Zod** validation and rate limiting. The React 19 frontend preserves drafts after failures, retries cleanly, and is keyboard- and mobile-friendly. Containerized into 4 Docker Compose services with health checks and tested with Vitest, Supertest, and Testing Library.
`Tech Stack: React 19, TypeScript, Vite, Express, Prisma, PostgreSQL, OpenAI API, Docker`

**Foodie — Online Food Delivery App**
Multi-page React app with client-side routing, **JWT authentication**, protected routes, and custom hooks.
`Tech Stack: React.js, React Router, JWT, Postman`

**Amazon Clone — E-Commerce UI**
Responsive storefront with Flexbox/Grid, async API calls for product data, and a dynamic cart with quantity updates and order tracking.
`Tech Stack: HTML, CSS, JavaScript, Day.js`
